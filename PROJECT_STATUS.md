# Verris — Status Projektu

> Single source of truth dla zakresu projektu, ustaleń i postępu prac. Zaktualizuj po każdym sprincie. Status referencyjnie pasuje do specyfikacji z pierwszej rozmowy (sekcje `2.x` panel klienta, `3.x` panel pracownika, `4.x` panel admina) oraz ustaleń (CloudLinux LVE + LiteSpeed + DirectAdmin po API, Stripe → PayU, billing per‑user wallet/card, autoscaling realne przez LVE).
